Contributing to Gilded Rose Refactoring Kata
======

This repository is a starter for practicing the C# xUnit kata. Please do not submit kata solutions to the [upstream project](https://github.com/emilybache/GildedRose-Refactoring-Kata).

For corrections or improvements to the upstream starter, see [Emily Bache's contributing notes](https://github.com/emilybache/GildedRose-Refactoring-Kata/blob/main/CONTRIBUTING.md).
